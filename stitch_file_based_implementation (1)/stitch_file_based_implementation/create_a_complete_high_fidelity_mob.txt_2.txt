01. CRITICAL BUGFIX: VIETNAMESE TYPOGRAPHY & TEXT OVERFLOW
============================================================
Vietnamese text with compound tone marks (ê, ư, ơ, dấu hỏi, ngã, nặng) is 20-30% wider and requires taller vertical line clearance than English. Fix all text-clipping and overflow issues immediately:

1. LINE-HEIGHT & VERTICAL CLIPPING:
- NEVER use `leading-none` or rigid tight line heights on Vietnamese text.
- Minimum line-height for body/headings must be at least `line-height: 1.35 to 1.5` (e.g., `text-[14px] leading-[20px]`, `text-[16px] leading-[24px]`).
- Ensure adequate top/bottom padding so diacritics are NEVER clipped by parent containers.

2. HORIZONTAL OVERFLOW & CONTAINER FIT:
- NEVER use fixed widths (`w-[240px]`, `w-44`) with `whitespace-nowrap` on text containers in a 360px–390px mobile viewport.
- Any flex child with text MUST include `min-w-0` to allow proper wrapping or controlled truncation.
- For buttons with long Vietnamese text (e.g., "Đăng ký tham gia", "Nhập mã vé thủ công"): use `flex-wrap` or allow multi-line wrapping, or adjust padding. Text must NEVER bleed outside button borders.
- Replace arbitrary card heights with auto-expanding layouts: `min-h-[...]` instead of rigid `h-[...]`.

3. STRICT 8-LEVEL TYPE SCALE (RESTORE FROM GUIDELINE V1.0):
